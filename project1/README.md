# Project 1 — SlotWise Booking Bot

SlotWise is a conversational booking automation bot built with:

- n8n
- Telegram
- Groq or another supported LLM API
- Google Sheets

## Required flow

1. Greet the user
2. Ask whether they want to book a table or appointment
3. Ask for service or booking type
4. Ask for preferred date and time
5. Offer 2–3 available mock slots
6. Confirm the selected slot
7. Log confirmed bookings to Google Sheets
8. Handle and separately log off-script messages
